# Project 01 — My First AI Personal Assistant

## Overview
My first AI automation project built using n8n and Google Gemini.

## Objective
Build an AI-powered personal assistant that accepts user messages and generates helpful responses using an LLM.

## Technologies
- n8n
- Google Gemini API
- AI Agent
- Chat Trigger

## Workflow Architecture
1. User sends a message through the n8n chat interface.
2. Chat Trigger receives the message.
3. AI Agent processes the message.
4. Google Gemini generates the response.
5. The response is returned to the chat interface.

## Features
- Conversational AI
- Custom system prompts
- Natural language responses
- Gemini API integration
